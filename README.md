# E-Katalog Inovasi Hasil Penelitian Poltekkes Kemenkes Tasikmalaya

Showcase dan portal elektronik interaktif produk dan luaran hasil penelitian dosen/peneliti Politeknik Kesehatan Kementerian Kesehatan Tasikmalaya.

## 🚀 Fitur Utama
- **Pencarian Real-Time & Filter Multi-Kategori**: Jurusan (Kebidanan, Keperawatan, Kesehatan Gigi, Gizi, RMIK, Farmasi), Jenis Inovasi, TKT, dan Status HKI.
- **Tampilan Fleksibel**: Tampilan Grid Card View dan Table/List View.
- **Modal Detail Interaktif**: Spesifikasi riset lengkap, tim peneliti, dan kontak.
- **Fullscreen Lightbox Image Viewer**: Zoom in/out pada gambar & poster penelitian hingga 350%.
- **Ekspor & Cetak**: Ekspor CSV/Excel dan format siap cetak booklet katalog resmi (Print to PDF).
